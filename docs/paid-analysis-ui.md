# 付费解读咨询入口

本地应用启动后，访问 `http://127.0.0.1:8501/?preview=paid` 可查看独立预览；演示命盘不会覆盖实际排盘资料。

实际页面在古籍检索成功后进入“AI 解读”，可选择“付费解读 / 自备模型”。

## 微信联系

付费解读页面显示作者微信 **bxzgf-bxbgf**，使用代码块自带的复制图标复制微信号，随后在微信中搜索添加。

标题下方提示：

> 不熟悉大模型 API、密钥申请或接入操作？可以添加作者微信，咨询付费解读。

添加时备注“子平术数”。解读范围、实际费用及交付方式在微信中沟通确认。

## 咨询范围

- 原局解读：参考 6.90 元。
- 原局、前六步正式大运详解与评分K线，再详解选定流年：参考 12.90 元。
- 再增加选定一个流月、一个流日：参考 19.90 元。

时间选择仍与专业细盘独立保留。首次可根据同命盘的专业细盘初始化，后续修改本页选择不会改动专业细盘或自备模型的时间范围。上级时间选择变化时，重新选择有效的下级范围。

此页只展示希望咨询的范围，不提交订单或自动调用作者模型。应用不展示微信/支付宝收款码，不接入支付 API、到账监听或支付后台。

## 自备模型与报告

自备模型继续使用原有平台、模型、密钥、上下文及原文引用校验流程。生成成功后可下载 HTML、TXT、JSON；HTML 可离线打开后通过浏览器打印为 PDF。

电脑版继续使用本机 Streamlit；另有可独立运行的安卓触屏界面，见 [安装包说明](install-packages.md)。两个版本均保留微信咨询入口，没有自动支付服务。
