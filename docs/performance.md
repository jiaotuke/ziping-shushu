# 启动与古籍检索优化

本轮修改针对源码网页版的首次打开、首次检索，以及后续交互中的重复工作。没有变更四本书各自的选篇规则、原文段落、标点或来源编号算法。

## 地点列表离线读取

- `china_regions.py` 优先读取 `data/regions/china_regions.json`，列表加载不发送网络请求。
- 地区数据单独记录来源、版本、许可和坐标覆盖范围，见 [SOURCE.md](../data/regions/SOURCE.md)。行政中心为近似位置，不代表具体医院。
- 未提供经度的地区不允许进行真太阳时修正。页面提示用户选择有经度的地点，或自行取消修正；程序不会自动替换位置或改变排盘时间口径。
- 只有快照不存在时，才尝试迁移读取已经下载到 `.cache/china_admin/` 的本地缓存；缺失资料会明确报错，不在打开页面时联网补取。

## 检索资源按需准备

- 源码版仍沿用 Chroma 和原有中文嵌入模型；获取检索句柄、读取已入库原文不再预先初始化嵌入模型。
- 首次真正进行语义查询时仍需要加载模型；本地没有模型时可能需要下载，缓存继续位于 D 盘项目目录。
- Windows 便携版继续使用原来的中文双字 BM25 排序，分词统计延迟到实际排序时准备。没有将源码版的向量排序替换为 BM25。
- 书籍阅读标签顺序不变；先完成能精确定位的书，再执行《子平真诠》的候选篇章排序。《三命通会》没有日时原文精确匹配时，仍按原规则使用书内检索。

## 解析缓存与更新

- 每本书分别缓存书名头和段落解析结果；读取某本书不再重复读取其余书籍全文。
- 源文件路径、修改时间、大小等元信息改变时，对应缓存自动失效；《子平真诠》的章节位置 JSON 也参与版本检测。
- 返回给调用方的是独立副本，界面或检索器增加字段不会污染其他请求中的原文记录。
- 进程重启后缓存重建。更新底本后，持久化向量索引仍须按原流程重建；解析缓存不会代替索引重建。

## 保留已有计算缓存

正常交互不再主动重载排盘、检索和报告模块，使已有大运、流月、流日的计算缓存能够跨页面刷新复用。

更新源码后应重启本地 Streamlit 服务，使全部模块使用同一版本。重启前先下载需要保留的报告；未完成的 AI 报告草稿仍只保存在原网页会话中。

本轮没有重新打包或发布安装包。已有 EXE/APK 不会随源码变化自动更新。

## 检查范围

本轮进行源码差异审阅与静态语法检查，没有运行自动化测试、真实模型调用或性能计时。此处说明减少了哪些重复工作，不承诺具体耗时或提速比例。
