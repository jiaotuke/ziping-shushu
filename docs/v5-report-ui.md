# 第五版报告布局

## 结果在前

1. 第二、三档先显示前六步大运的真实 SVG K 线，横轴为运柱、年份和虚岁区间，纵轴为 0–100 项目解释性评分。开、收、高、低仍由代码从年度评分计算，金点表示整运综合分；缺分不补造蜡烛。
2. 点击蜡烛或大运按钮，显示该运白话总评、可把握方向与留意事项，以及事业与学业、财务与资源、感情与合作三张卡片。每张卡片一条结论、一条建议。不新增健康或心境，不新增分领域数值分数。
   卡片下方同时显示本运整体解释、有利与留意之处，以及可展开的运干、运支、格局、分领域说明与评分依据。随后列出该运十年已有的逐年评分和完整理由，首年默认展开，可逐年展开或一键展开全部。点击其他大运时，说明与年份同步切换；直接使用已有报告，不再调用模型。
3. 另列专业细盘所选流年及可选流月、流日的重点，按需展开其分项解读。选中的流年属于前六步之一时，图表初始选中对应大运；否则从第一运开始，所选流年仍单独显示。
4. 原局报告没有年度评分，直接展示原局概览和三方面，不能凭原局分数补造子平 K 线。

点击图表在组件内切换，不发起模型请求、不刷新整页、不改专业细盘的运年选择。支持键盘 Tab、Enter / 空格和手机横向滑动；组件重复收到同一资料时保留选择，避免反复渲染和闪回。

## 推导在后

原局八步、原局关系、各运干支作用、好坏、三个领域的完整说明、评分维度、年度调整、引用和局限放到“查看完整推导与古籍依据”，默认折叠。摘要不能替代详细判断，也不把综合分反推成三个领域的结论。

模型输出增加 `overview` 和 `life_domains`，同时保留原详细结构及一次自动修正机制。摘要使用日常语言，保留适用条件；领域键与显示顺序由程序核验，引用仍可选。评分算法和权重不变。

## 岁运标识与恢复

报告标识绑定本次程序请求，例如第四步大运为 `luck:4`。同义编号 `4`、`第4运`、全角标点或无歧义的单层报告包装可在本地规范化；没有标识时由本次请求补入，再检查完整年份、关系覆盖及全部报告字段。明确指向其他运次、运柱、时间范围的内容仍拒绝，不能强行改标签当作本运。

继续时先对保存的岁运草稿做上述检查，若全部内容通过则直接恢复，不调用模型。仍有缺项时，使用更新后的具体诊断请求修正；模型明确收到 `required_stage_id`。页面直接显示期望和实际标识，并可下载本段草稿与问题记录。原局及已完成大运继续保留，正常化不修改评分算法或已完成阶段。

## 旧报告与下载

- 原始事实、来源、模型及设置精确一致时识别第四版签名，保留已完成阶段。旧领域内容只摘录已有文字并标明，不自动补造新建议或额外调用模型。重新生成完整第五版报告才会更新全部白话字段。
- HTML 含相同的离线交互图表，全部代码和样式内嵌，无 CDN、外部字体或网络请求。内容 JSON 做脚本边界转义，模型文本用文本节点或 HTML 转义；可执行脚本采用 CSP 精确哈希授权。
- HTML 打印输出全部大运与所选时间的概览、完整推导，不只打印当前选中的一运。TXT 先概览后推导，JSON 导出完整模型字段及程序评分。下载不触发模型请求。
- 网页、下载 HTML 与文档中的图表名称统一为“子平 K 线”。年度缺分保留待核，未新增年度评分算法，也不为显示十年列表而补造内容。
- 0.5.0 将同一报告界面纳入 Windows/安卓安装包；交付检查覆盖构建、静态语法及文件清单，没有运行自动化测试、真实模型调用或跨设备试装。正式解读需先排盘和检索，没有新增无需排盘的示例入口。
