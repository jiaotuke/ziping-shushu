# 安卓0.7.0本地版

面向Android 8.0及以上的ARM32/ARM64手机。使用原应用ID与签名，可覆盖安装旧版本。安装前下载保存旧报告；本次会话与API Key不会跨退出保留。

支持本地公历、农历、四柱排盘；四柱自动反查匹配日期；岁运关系与古籍检索。自备模型支持智谱、DeepSeek和书生·端砚，分别填写密钥。先完成基础报告，可在阶段之间暂停；之后可反复生成独立流年、流月或流日报告。第三档可导入JSON、HTML、TXT基础报告，最大2MB。专项导出只含所选层级。

运行 `tools/build_android.ps1` 构建。JDK17、Gradle8.9、Android SDK、Python3.10、缓存与临时文件优先放D盘项目目录；脚本只从白名单收集源码与已安装依赖。保存自己的签名材料，不提交Git。公开源码未附《千里命稿》完整转录，有适用权限的兼容底本可自行放入data/source目录。安装包仅申请联网权限；导入导出使用系统文件选择器。

APK已经完成发布构建与签名检查，但没有真实手机验收，也没有调用模型生成报告。AI结果与命理条件仍需人工核对。
