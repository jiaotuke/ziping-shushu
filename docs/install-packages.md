# 安装包使用说明

当前构建版本 **0.5.0**，包含子平 K 线、三项概览、整运解释与十年评分。Windows/安卓均采用正式排盘、检索后解读的流程；没有新增无需排盘示例入口。文件大小、SHA256 与发布说明见 [v0.5.0](releases/v0.5.0.md)。

仓库另有尚未打包的启动与检索优化：源码网页版已改为本地地区列表、古籍解析缓存及按需加载检索资源，详见 [优化说明](performance.md)。下文描述的 0.5.0 安装包尚未包含这批修改；Windows 后续重新构建时会携带离线地区资料。

## Windows 电脑版

分享文件：`dist/ZipingShushu-Windows.zip`。

1. 将 ZIP **完整解压**到可写目录，例如 D 盘的「子平术数」文件夹。
2. 双击文件夹中的 `ZipingShushu.exe`，稍等浏览器自动打开。
3. 保留启动窗口；关闭该窗口即可结束本地服务。关闭网页标签不会结束服务。

适用 Windows 10/11 的 64 位电脑。无需安装 Python、Git 或单独下载向量模型。
**不要把 EXE 单独拿出来发送或运行**，同目录 `_internal` 文件夹也是程序的一部分。

默认使用输入的当地钟表时间，可离线排盘、查看岁运和检索古籍。需要真太阳时修正时，勾选加载出生地点，联网选择省、市、县区，再勾选经度修正；行政区列表会缓存在本机。

用户缓存保存在 EXE 旁的 `user-data` 文件夹。更新时保留自己的该文件夹，不要将它发给别人。分享给用户时应发送打包脚本生成的干净 ZIP。

## 安卓手机版

分享文件：`dist/ZipingShushu-Android.apk`。

1. 把 APK 发到安卓手机，下载到手机本地。
2. 用文件管理器打开；如果系统提示，允许该文件管理器安装应用，然后继续安装。
3. 打开「子平术数」，选择日期、性别并排盘。

安装包面向 Android 8.0 及以上的 ARM 手机，包含 64 位和 32 位 ARM 运行环境。手机独立计算，不需要电脑保持开机、共享网络或运行网页服务。它不是 iPhone 安装包。

手机界面针对触屏重新排版，保留公历、农历、四柱输入、专业细盘、四条横向岁运选择带、关系、四本古籍、译文、咨询及模型解读。手机的真太阳时修正在公历页选填经度与 IANA 时区，不使用电脑版的省市县选择器；未填经度按当地钟表时间排盘。

仅填写四柱而未提供真实出生时刻时，可以看原局；计算大运需要补填与四柱匹配的出生时刻。起运默认按时辰折算。

## AI 与咨询

- 排盘、岁运、古籍定位在设备本地运行；AI 解读和 AI 译文需要联网。
- 「自备模型」中选择智谱或 DeepSeek，填写该平台自己的 API Key；费用、限额及可用模型以平台账户为准。点击生成或翻译后才调用模型。
- 不熟悉接入方法，可在「付费解读」复制作者微信 `bxzgf-bxbgf`，通过微信沟通范围、费用和交付。本应用没有收款码、自动支付、订单或收款通知监听。
- 安卓 API Key 仅保留在当前应用会话，不写入本地配置、报告或安装包。退出应用后需要重新填写。安卓本次排盘与解读也不自动保存，报告请及时下载。
- 自备模型报告通过引用检查后，可导出 HTML/TXT/JSON。HTML 可离线打开，电脑浏览器可打印保存为 PDF。
- 安卓译文分批保存到应用私有缓存，可点击继续生成；清除应用数据或卸载会删除缓存。

## 与源码运行版的区别

安装包不附带大型向量模型。四本书各自的日干、月令、篇章定位规则继续复用；需要对候选段落排序时，采用中文双字 BM25 关键词排序，**不等同于向量语义检索**。原文仍以完整段落及篇章展开，保留出处。源码运行版仍可使用原有向量检索。

AI 上下文裁剪、八步解读和引用检查复用现有实现。字面引用校验通过，不代表古籍解释或命理结论已经人工确认。

## 构建与交付范围

本轮完成 Windows EXE 与已签名 Android APK 构建、静态语法检查和发布文件清单检查；没有运行自动化测试，没有在真实安卓设备或其他电脑上试装，也没有调用外部模型。首次分享可先让少量用户反馈具体机型与启动情况。

安装包按白名单收集程序和四本古籍，不包含开发环境的模型密钥、报告、个人收款配置或安卓签名私钥。

## 开发者重新打包

全部工具、缓存和临时构建文件放在 D 盘项目目录。当前构建环境：Python 3.10、PyInstaller 6.22.3、Chaquopy 17.0.0、JDK 17、Gradle 8.9、Android SDK 35。Windows 构建依赖锁定在 `packaging/windows-lock.txt`。

准备好相应的 `.tools/windows-build` Python 环境，以及 `.tools/java17`、`.tools/gradle/gradle-8.9`、`.tools/android-sdk` 后，在项目目录运行：

```powershell
.\tools\build_windows.ps1
.\tools\build_android.ps1
.\.venv\Scripts\python.exe tools/package_releases.py
```

安卓打包使用 `.venv` 中的 `lunar_python`、`tzdata`、`certifi` 纯 Python 包，按白名单暂存，避免手机首次启动安装依赖。首次构建需要联网获取 Gradle 依赖；脚本已将相关缓存指向 D 盘。

Windows 每次在 `.tmp/windows-release-<唯一编号>` 中生成全新目录，避免覆盖正在运行的旧版或删除其用户数据；`.tmp/windows-release-location.txt` 记录本次路径，ZIP 打包脚本自动读取。分享更新后的 ZIP，解压到新文件夹即可使用。

安卓签名文件在 `.local/android-signing`，**请单独私密备份整个目录**，不要上传 GitHub 或随安装包分享。以后要让用户覆盖安装升级，必须保留相同签名并递增 `app/build.gradle` 的 `versionCode`；更新古籍资源时也应递增 Java 资源目录 `core-data-v2` 的版本。
