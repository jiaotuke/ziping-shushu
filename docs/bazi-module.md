# 排盘模块：先理解输入和输出

## 这个模块做什么

`bazi.py` 调用现成的 `lunar-python` 库，把公历年、月、日、时分秒换成农历信息和年柱、月柱、日柱、时柱。四柱各有两个字，合称八字。

核心步骤可以在 `calculate_chart()` 里看到：先用 `Solar.fromYmdHms(...)` 建立公历时间，再 `getLunar()` 得到历法对象，最后通过 `getEightChar()` 取四柱。具体干支历法计算由依赖库完成。

## 当前约定

- 命令行当前接收公历日期和当地民用钟表时间；代码中的 `calculate_lunar_chart()` 也能接收农历年月日和闰月标记，并先转换成公历时刻再复用同一排盘流程。
- 当前默认按 `lunar-python` 的 `sect=2` 计算日柱；可传 `--sect 1` 对照另一种换日规则。
- 可选输入出生地经度和 IANA 时区，例如 `--longitude 116.4 --timezone Asia/Shanghai`，程序会另行输出真太阳时和修正后的四柱。
- 时区按出生日期的规则计算 UTC 偏移，因此能处理夏令时；若遇到夏令时回拨产生的重复钟点，需要用 `--fold 0` 或 `--fold 1` 指定是哪一次。
- 这里只负责排出四柱，不代表已经完成命理分析。

`calculate_chart()` 的返回值还包含 `检索条件`：日主、月令、四柱透干集合和四支藏干集合。后续网站可以把这组结构化字段传给 RAG 的条件过滤接口，而不必让大模型从四柱字符串里猜条件。

## 真太阳时是怎样修正的

钟表时间先依据出生地时区换算；经度用于把时区所用的民用钟表时间调整到出生地经线，再加上地球公转和自转造成的“均时差”。本项目按 NOAA 公布的近似公式计算：

```text
修正分钟 = 均时差 + 4 × 经度（东经为正）- 60 × 当地 UTC 偏移小时
真太阳时 = 当地民用钟表时间 + 修正分钟
```

因此，时区和经度缺一不可。纬度影响太阳高度和方位，但不影响这个时间换算。例子（经度仅作示意）：

```powershell
.\.venv\Scripts\python.exe bazi.py "1990-01-01 12:00" --longitude 116.4 --timezone Asia/Shanghai
```

这套太阳时换算使用 NOAA 的简化均时差公式，适合本项目学习和对照，不是高精度天文历算。出生时间若正好在时辰或日期边界附近，几分钟差异也可能改变时柱或日柱；程序会同时保留并显示原始时间排盘与修正后排盘，便于人工核对。若当地时间落在春季夏令时跳过的不存在钟点，程序会报错提示核实；夏令时回拨的重复钟点须显式选择 fold。

## 为什么要留意规则

一般时刻可能两种规则算出相同结果；接近子时换日边界时，日柱可能不同。节气交接附近的年柱、月柱也值得用可信排盘结果核对。库提供了可复用的计算实现，但不同传统对边界规则的约定不一定相同，所以输入地点、时间基准和采用流派应逐步明确。

## 运行示例

```powershell
.\.venv\Scripts\python.exe bazi.py "1990-01-01 12:00"
.\.venv\Scripts\python.exe bazi.py "1990-01-01 23:30" --sect 1
.\.venv\Scripts\python.exe bazi.py "1990-01-01 12:00" --longitude 116.4 --timezone Asia/Shanghai
```

当前先用一条命令练习“出生时间如何变成四柱”。之后再决定要不要加入藏干、十神、大运等字段，并逐项和你认可的排盘结果对照。

## 自动化测试

项目使用 Python 自带的 `unittest`，无需额外安装测试框架：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

测试分层检查：

1. **公式基准值**：用固定日期检查 NOAA 均时差近似公式，防止符号、单位或日期处理被改坏。
2. **换算性质**：东经每增加 1 度，太阳时应增加 4 分钟；位于时区中央经线时，经度与时区偏移相消，只剩均时差。
3. **时区边界**：检查夏令时跳过的时间会报错、回拨的重复时间要求选 fold，并核对两次选择相差约一小时。
4. **日期边界和输入**：检查修正后跨日、非法经度和无效时区。
5. **排盘集成**：用 `lunar-python` 项目测试中的四柱样例核对封装输出，并确认子时换日选项确实影响日柱。

这些自动化测试能发现代码回归，但不能单独证明命理规则符合你所采用的门派约定。库的四柱结果还应与一份你认可、设置一致的排盘资料做验收；验收样例应记录输入、出生地、换日规则、真太阳时设置和预期四柱，作为后续固定回归用例。
