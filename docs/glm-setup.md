# 接入智谱与 DeepSeek 模型

在 AI 解读页面先选平台、再选模型。支持智谱国内平台与 DeepSeek 官方 API，使用 Python 标准库请求接口，无需下载模型或安装额外 SDK。只调用当前选择的模型，失败时可手动切换。

| 平台 | 内置模型 ID | 计费说明 |
| --- | --- | --- |
| 智谱 | `glm-4.7-flash` | 免费，限额以平台为准 |
| 智谱 | `glm-4.7-flashx`、`glm-4.7` | 按量计费 |
| 智谱 | `glm-5.3-flash`、`glm-5.3-flashx`、`glm-5.3` | 按量计费，必须开启思考 |
| DeepSeek | `deepseek-flash`、`deepseek-v4-pro` | 按量计费 |

两家均提供“自定义模型 ID”入口，需使用对应平台支持长上下文、思考模式参数和 JSON 输出的模型。GLM-5.3 系列在页面上固定开启思考，请求层也会强制启用：报告采用 `high` 思考强度；连接检查采用 `low`，最多 4096 输出 Tokens、90 秒超时，其用量包含思考开销。其他内置模型的连接检查使用短句并关闭思考。默认仍为免费的 GLM-4.7-Flash，不会自动切换付费模型。

GLM-5.3 系列的思考与采样参数按[旗舰模型文档](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3)和 [Flash 系列文档](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)适配。新模型是否更适合本项目的八字解读，尚需实际报告对比，不能只凭版本号判断。

DeepSeek 模型名称以[官方接口说明](https://api-docs.deepseek.com/)与[价格页](https://api-docs.deepseek.com/quick_start/pricing/)为准，当前 Flash ID 为 `deepseek-flash`。旧的 `deepseek-chat` 和 `deepseek-reasoner` 已公告退役，不列入默认选项。智谱模型见 [GLM-4.7 系列](https://docs.bigmodel.cn/cn/guide/models/text/glm-4.7)。

## 创建智谱 API Key

1. 打开 [智谱 BigModel](https://bigmodel.cn/)，注册或登录。
2. 按平台要求完成账号认证和服务开通。
3. 在控制台找到“API Key”或“API 密钥”，创建并复制密钥。
4. 在平台确认 `GLM-4.7-Flash` 仍标注免费，并核对账号的速率及并发限制。免费政策与限额以平台为准。

模型和调用方式见 [官方模型文档](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash)。这里使用国内 BigModel 的账号及密钥。

## 创建 DeepSeek API Key

1. 登录 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 在 API keys 页面创建密钥，核对余额、模型价格与调用权限。
3. 在本机 AI 解读页面选择 DeepSeek 和需要的模型，在“模型连接设置”填写该平台密钥。

DeepSeek 网页聊天与 API 的服务和额度分别管理，不能因网页聊天免费就认为 API 免费。

## 在网页中填写

1. 打开本机网页，完成排盘并点击“古籍检索”。
2. 点击“AI 解读”，选择平台、模型及是否启用深度思考，再展开“模型连接设置”。
3. 在密码输入框中粘贴 API Key，点击“检查连接”。这一步只发送一句测试短句。
4. 连接正常后点击“生成 AI 解读”。这一步将四柱、十神、《子平真诠》全文及本次检索资料发送至当前选择的平台，可能等待一至三分钟或更久。

网页输入的密钥只保留在当前会话中，不写入文件、不保存到报告。不要将真实密钥发到聊天、截图或代码仓库中。

## 可选：保存到项目本地配置

将项目 `.streamlit/secrets.toml.example` 复制为同目录下的 `secrets.toml`，在文件中填写：

```toml
GLM_API_KEY = "你的智谱API密钥"
DEEPSEEK_API_KEY = "你的DeepSeek API密钥"
```

可只填写需要的平台。`secrets.toml` 已被 Git 忽略。新增此文件后重启 Streamlit；也可设置对应进程环境变量 `GLM_API_KEY` / `DEEPSEEK_API_KEY`。网页临时输入优先，其次是环境变量，再其次是本地 secrets 文件。切换平台会分别保留当前会话内输入的密钥，不会将智谱密钥发给 DeepSeek。

## 当前分析方式与限制

- 依次分析：排盘事实 → 日主月令 → 全局结构 → 旺衰强弱 → 格局成败救应 → 取用喜忌 → 大运资料检查 → 结论与待核条件。
- 《子平真诠》全文作为方法资料提供，包含底本所附评注。其余古籍从本次检索范围中选取完整原文段落，每本最多约 6000 字符；不截断段落。当前版本直接提供资料，尚未实现模型自主调用查书工具。
- 引用 ID 和摘录须与提供给模型的原文逐字对应，校验失败时不展示为合格报告。这是出处检查，不是语义正确性的证明。
- 当前程序没有计算大运、起运年龄及流年作用，因此第7步固定说明资料缺失，不生成这部分预测。
- 切换命盘、资料、平台、模型或思考模式后，旧解读会失效。只有主动点击按钮才发起 API 请求；限流或错误时不自动重试，也不自动切换至付费模型。

## 上下文管理与引用失败处理

- “上下文与资料范围”展示模型窗口、输入保守估算、思考与报告预留及安全余量。内置 GLM-4.7 系列按 200K 窗口，GLM-5.3 系列及当前 DeepSeek 模型按 1M 窗口管理。
- 目前按实际消息 JSON 的 UTF-8 字节长度加消息开销保守估算，**不是对应模型 tokenizer 的精确计数**，可能提前判为不足；实际输入用量以接口 usage 为准。不会用其他模型的 tokenizer 冒充精确值，也不下载模型。
- 思考开启时预留 32768 输出 Tokens，关闭时预留 8192，另保留窗口 5%（最低 4096）的余量。自定义模型需手动填写官方窗口，默认按 32768 处理，输出预留不超过窗口四分之一。当前未适配任意自定义模型的独立输出限制，需选支持对应预算的模型。
- 《子平真诠》全文和评注完整保留，按书名和篇章组织。窗口不足时仅移除其他古籍完整段落，并显示省略数量；方法书仍放不下时停止请求，提示切换模型，不截断全文。
- 只发送排盘资料和本次文献，不累计历史报告。引用 ID 改为本次资料内的短编号，原始 ID 在本机映射保存。
- 引用校验只允许自动恢复可核对的空白差异，或将摘录唯一对应至已有来源；更改留有记录。不会用语义相似度替代原文检查。短句无法唯一确定出处、改字、添加省略号或编造内容仍会被拦截。
- 引用失败时在当前会话保留待核报告和具体问题，展示实际步骤编号及“编号不存在 / 摘录不匹配 / 缺少引用”。点击“修正引用并重新校验”才会再次调用当前模型，发送原资料、待核报告和问题，重新检查预算和所有引用；不自动重试或收费。刷新重建会话或重启服务可能丢失待核稿。
- 同一命盘检索成功后，“古籍检索”只切换至原文页面，复用已有结果；重新排盘会清除旧检索并允许执行新检索。
- 密钥或权限错误、限流、网络失败、输出截断和引用失败都有对应提示。真实接口是否可用，需要你填写密钥后点击“检查连接”确认。
