# 第一个网页：Streamlit

## 这个网页做什么

`app.py` 是目前的网页入口。它把已有的排盘代码和古籍检索代码接到浏览器界面上：

1. 页面收集公历或农历出生日期和时间，并通过省、市、县区三级选择出生地点（仅中国）。
2. 点击“开始排盘”后，`make_chart()` 调用 `bazi.py` 计算四柱，并显示各柱天干十神、地支藏干十神、纳音和旬空。
3. 点击“古籍检索”后，页面按书名分开检索所有已录入文本。
4. 四本古籍分别进入自己的检索器，按各自的篇章结构和命盘线索定位候选原文；检索器没有适用候选篇时，才在该书自身的文本范围内做语义参考。
5. 检索成功后可以在四本书名标签间切换。每条结果都显示书名、篇章/原文位置和来源记录。
6. “AI 解读”在古籍检索成功前处于禁用状态；成功后可填写智谱 API Key，检查连接，再调用 `GLM-4.7-Flash` 生成带原文依据的八步解读；操作见 [接入说明](glm-setup.md)。

《穷通宝鉴》根据日主与月令定位对应篇章（例如癸水生于丑月优先定位“十二月癸水”），并检查人工整理的条件标注；命中后展示整章，未命中时只在对应篇章内展示一条语义参考。《三命通会》分四层检索：日柱与时柱组合、日干专论、日干生月、日主五行生月。例如癸丑日庚申时依次使用“癸丑日庚申时”“论癸日干”“癸生丑月”“水生丑月”作为线索；每层独立返回一条结果，日时组合先查原文精确字串，其余层级优先限制到对应篇章，命中后展开该篇章全文。《子平真诠》依据用神、月令和十神专论选篇；《滴天髓》仅索引“七、天干”中的十干专论，按命盘日干精确返回“论甲日干”至“论癸日干”中对应的一篇，不做语义回退；每篇按正文、原注和任氏注分段展示，保留原文标点。“论某日干”为整理篇名，不写入原文。后三本目前都没有经过充分人工标注，篇章被选中只表示检索相关，不代表古籍条文已确认适用于命盘。《子平真诠》文本为带评注版本，《滴天髓》文本为任铁樵注本，页面会保留这些版本来源说明。

各书检索逻辑位于 `book_retrievers/`，由 `registry.py` 按书名明确分派。`common.py` 只共享出处过滤、向量排序和篇章展开等基础操作，不决定哪一篇适用于哪本书。未知书名会报错，不会默认套用其他书的规则。

十神、纳音、旬空和藏干来自 `lunar-python` 的 `EightChar` 接口。命局神煞首批依《三命通会》卷二、卷三中明确的查表规则计算，包括禄神、金舆、天乙贵人、羊刃、驿马、劫煞、亡神、灾煞、六厄、咸池、将星、华盖、孤辰寡宿、空亡和十恶大败；每项会显示命中柱位、起法和篇目。原文同一项目出现异说时，代码注明当前选择；页面只报告规则命中，不据此判断吉凶。农历日历神煞不作为命局结果展示。

Streamlit 通过 Python 脚本描述页面。用户操作控件时，脚本会重新运行；`st.session_state` 用来保留已经算好的结果。你可以从 `app.py` 的页面标题、输入控件、按钮和结果页签开始读。

## 在本机运行

在项目目录打开 PowerShell，运行：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8501`。这个地址只在运行程序的电脑上可用；其他人现在还不能通过互联网访问。

行政区选项由 DataV.GeoAtlas 的 GeoJSON 服务按级别加载，并缓存在项目 D 盘的 `.cache/china_admin/`。省、市、县区三个控件始终显示；未选择上一级时，下一级控件保持禁用状态。若某个城市没有下辖县区（例如县级市），县区控件会隐藏，并直接采用该市中心坐标，不会当作行政区不存在。真太阳时计算使用所选区县或城市中心坐标和对应时区。中心坐标只是近似位置，不是具体出生医院的坐标。地点选择不需要发送出生日期或时间。

出生信息控件放在 Streamlit fragment 中；修改输入时只刷新这一小块，不重绘结果区域。开始排盘后按钮会锁定，避免重复提交。第一次访问尚未缓存的省份或城市时，列表仍需从在线服务加载；加载完成后会使用 D 盘缓存。

如果 Streamlit 尚未安装，先把 pip 缓存和临时文件放在 D 盘，再安装：

```powershell
$env:PIP_CACHE_DIR = 'D:\ai bazi\.cache\pip'
$env:TMP = 'D:\ai bazi\.tmp'
$env:TEMP = 'D:\ai bazi\.tmp'
New-Item -ItemType Directory -Force $env:PIP_CACHE_DIR, $env:TEMP | Out-Null
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 当前版本的边界

- 地点坐标来自行政区边界数据的区县中心，不保证是具体医院坐标。
- 当前行政区选项依赖 DataV.GeoAtlas 在线服务；若接口不可用，地点列表无法加载。
- 《穷通宝鉴》的结构化条件索引目前只有一条例子标注，所以大多数命盘显示篇章内参考；其他三本目前只做语义参考，没有可宣称适用的条件标注。
- AI 页签尚未调用大模型。
- 此版本只在本机运行。公开给别人使用需要先把代码部署到云端，并确保古籍文件、索引、依赖和模型缓存能在云端取得。

## D 盘缓存

网页通过 `rag.py` 建立向量模型时，模型缓存目录是项目下 `.cache/huggingface/`。`.cache/` 已加入 `.gitignore`，不会作为普通项目源码上传。
