# 子平术数 Agent Skill

下载 [v0.6.0 完整技能包](../releases/v0.6.0/ziping-shushu-skill-v0.6.0.zip)，解压后得到 `ziping-shushu` 文件夹，包含 SKILL.md、指令、脚本、计算模块和四本固定古籍底本。只分享 SKILL.md 会缺少运行所需文件。

将整个文件夹安装到支持文件型 Agent Skills 和本地 Python 执行的环境。需要 Python 3.10+；依赖在技能目录的 requirements.txt 中。安装依赖前把下载缓存设到目标设备的数据盘，本项目优先 D 盘。不同 Agent 对脚本执行、依赖安装和文件导出的支持不同，需要在目标环境核对；本次没有完成跨平台验收。

使用时提供公历／农历出生日期与时间，或四柱。四柱有多个匹配公历日期时先选择日期。需要大运时还需提供性别。普通排盘、基础解读和查询大运表不会自动追加评分与K线。

明确说“分析这步十年大运”“分析前六步大运并给出K线”才进入扩展流程；没指明哪步时先确定范围。一步十年不自动扩大为六步。AI按阶段撰写分析，本地代码校验结构与引用、计算分数并生成 HTML/TXT/JSON/SVG。每步大运一根十年蜡烛，年度细节可展开；分数是解释性指标，不是事件概率或古籍自带数值。

技能入口不调用作者模型API，不包含作者密钥、代理账号、业务数据库或本机管理程序。当前 Agent 读取资料和生成报告仍会消耗其自身模型额度。Token文档仅为规划假设，未用真实分析输出实测。

任务进度和报告保存到技能目录之外，不要连同出生资料、报告或草稿一起分享。格式检查通过不等于报告准确性或跨平台兼容性已获验证。

古籍电子底本的来源与许可状态见 [SOURCE.md](../data/source/SOURCE.md)。本压缩包用于技术分发，不代表所有底本已经取得商业再分发授权。
