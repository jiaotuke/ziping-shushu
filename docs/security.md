# 公开站点的基础安全控制

这份实现减少常见滥用及资源耗尽风险，不代表完整安全审计或抗DDoS服务。管理员界面、完整账本、作者模型密钥不在公开部署包中。

## 服务端频率与并发限制

仅在 `ZIPING_PUBLIC_SITE=1` 时启用；本机作者工作台和SSH维护导入不受访问者额度限制。

| 操作 | 同一来源限制 | 全站限制 |
| --- | --- | --- |
| 代理登录 | 每分钟15次、15分钟60次；原有账号15分钟6次失败仍保留 | 每分钟120次 |
| 验证码获取 | 每分钟12次、15分钟40次 | 每分钟120次 |
| 新咨询登记 | 每分钟3次、每天20次；相同请求编号重试不重复登记 | 每分钟30次、每天500次 |
| 排盘及四柱日期反查 | 每分钟20次、每小时200次；不重复扣除未变化的反查输入 | 每分钟120次 |
| 新古籍检索 | 每分钟10次、每小时100次；已完成检索的切换不扣次数 | 每分钟90次 |
| 解读或译文生成 | 各自10分钟3次、每天12次 | 各自每小时20次 |
| 模型连接检查 | 5分钟6次 | 每小时30次 |

AI解读、译文及模型连接检查共用全站2个任务名额，同一来源同时1个。忙碌时不清空已有报告和阶段进度。任务用共享SQLite租约和心跳登记；进程异常时，遗留名额最长5分钟过期。此额度是保守起点，不是实测容量保证。

登录连续失败3次后显示一次性图片验证码；验证码与来源绑定，3分钟过期，校验后失效。验证码只能提高自动尝试成本，仍需频率限制和强密码。

## 可信来源与隐私

公开服务的Caddy覆盖 `X-Ziping-Client-IP` 为真实连接来源，网站8501端口仍只映射到服务器回环地址。只有该代理部署启用 `ZIPING_TRUST_PROXY_HEADER`；不得在可绕过代理直连的服务上盲目信任客户端头。后续接入CDN时，应同时重新核对真实来源的可信代理配置。

限流库保存短期来源HMAC，不写入原始IP、用户名、出生信息或模型密钥；安全事件按分钟聚合。来源控制记录保留一天，聚合安全事件保留七天。来源密钥及控制库位于独立的运行数据目录，不能公开下载。

## 网关与资源

保留CORS/XSRF保护及HTTPS，关闭静态目录服务；HTTP请求体上限2MB、WebSocket消息上限32MB、断线会话保留120秒。网关限制请求头大小及读取时间，HTTP闲置连接2分钟超时；不设置会截断长报告的WebSocket总时长。

公开网站容器限制为1GiB内存、1.5CPU、256个进程/线程；网关限制为256MiB、0.5CPU、128个进程/线程。上限用于约束资源，不保证超过上限后仍能正常服务。

## 资源监控与备份

服务器定时任务每5分钟检查内存、磁盘、五分钟负载、网卡出流量和容器重启；默认告警阈值为内存/磁盘85%、负载3、当天网卡出流量粗估1GiB。启用前的流量不计入该粗估，网卡值不等于阿里云账单，告警不会自动停止计费。状态写入私有维护日志和本机后台“网站设置 → 安全状态与本机账本备份”；点击查看才建立SSH连接，没有手机或邮件推送。

本机业务保存后，用SQLite在线备份接口生成本机账本副本，保留最近60份自动备份，原有手动副本不删除。按维护者决定，没有设置云端数据库定期下载到本机；部署前的一致性备份仍保留。

系统已启用自动安全更新；不自动重启服务器。应用依赖与镜像更新通过白名单发布和健康检查完成，保留旧版本与回滚配置。

## 维护账户

SSH仅允许公钥认证；关闭密码、交互式密码、X11和SSH代理转发，限制认证尝试与未认证连接数量。动态管理出口IP场景不锁定临时地址；若以后获得固定出口，可进一步收紧安全组来源。阿里云账号多因素认证须由账号持有人自行启用。

此次只执行静态语法、配置验证和服务启动/连接验收，不运行自动化测试、模拟成交、模型生成或攻击压测。
