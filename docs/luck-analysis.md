# 完整大运、解释性评分与子平 K 线

## 第五版展示顺序

先显示真实 SVG 子平 K 线，点击蜡烛或大运按钮，在本地浏览器切换该运的白话总评和三个领域卡片：事业与学业、财务与资源、感情与合作。不新增健康和心境。没有岁运的原局报告显示原局概览，不编造 K 线。

所选流年及可选月日先显示重点，按需展开其分项卡片。原局八步、干支关系和逐运推导及引用在最后统一折叠。展示顺序变化不改变分析的依据顺序；三个领域的结论独立提炼，不根据综合分套模板。

已有第四版报告仍可显示旧领域说明的摘录，不会自动补出未生成的建议；输入与设置精确匹配时复用会话进度。用户主动重新生成后，模型输出独立的第五版白话字段。详见 [第五版布局](v5-report-ui.md)。

## 三种范围

1. 原局解读：八步原局分析，加原局关系的影响路径、可能现实表现、成立条件与反证。
2. 原局＋前六步大运、选定流年：从第一步正式大运起，只分析前六步；逐运说明好坏与事业、财务、感情，逐运评分并绘制子平 K 线，另详解所选流年。
3. 原局＋前六步大运、选定流年月日：包含第二项的六步大运，再分层详解所选流年、节月与流日。

报告从 `lunar-python` 返回的第一步正式大运开始取前六步，不包括未起运阶段，少于六步时按实际数量。完整历法表继续用于专业细盘选择和校验，不因报告缩短而限制所选流年。范围终点不表示寿命。大运及年度采用已有历法口径；交运当年仍须核对精确交接时刻，不能认为元旦即交运。

## 谁来分析，谁来画图

模型输出有引用的解释、维度分数及年度调整；代码检查覆盖范围与数值、计算加权总分与年度分，生成 SVG 图。不接受模型自己提供的总分、开收高低或画图坐标作为计算结果。

古籍没有现成的百分制。以下权重、阈值与年度调整幅度是本项目的产品规则，用来一致地表达模型对传统文本的解释，不是古籍原文规定、统计概率、实际人生数据或经过实证的预测模型。

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 格局与救应 | 35% | 是否支持原局格局、相神及救应，及破坏条件 |
| 喜忌与扶抑 | 30% | 结合原局根气、旺衰与实际作用，避免机械补印比或克泄 |
| 调候与通关 | 20% | 在条文适用条件下解释寒暖燥湿、对峙与调和 |
| 结构稳定与可用性 | 15% | 考察配对、位置、冲刑等对可用条件的影响；不按关系条数算吉凶 |

各维度 0–100；50 表示利弊均衡，上下调整须说明依据及反证。综合分为四维度分数乘固定权重后求和，保留一位小数。60 及以上标“偏有利”，40 及以下标“偏不利”，其余为“利弊交织”；这些标签也是项目阈值。

固定权重不等于模型判断确定不变。同一命盘重新生成或更换模型，维度分及年度调整可能变化；比较时应保留模型、报告版本与引用依据，不把分数精度当成预测准确度。

每个流年在综合分基础上给出 -30 至 +30 的解释性调整，年度分限制在 0–100。不是按固定干支表或“见合加分、见冲扣分”计算。证据不足用 `null`，不擅自补成 50 或 0；任一维度缺分则整步大运暂不评分。

每步大运一根 K 线：

- 开：运内第一个流年的年度分。
- 收：运内最后一个流年的年度分。
- 高、低：该运所有流年分的最大、最小值。
- 金色点：整步大运的加权综合分。
- 颜色：仅表示首末年度分差，不表示整步大运的好坏。年度分有缺项时不绘制完整蜡烛。

## 古籍引用与现实表现

复用《子平真诠》全文与评注、本次检索到的《穷通宝鉴》《三命通会》《滴天髓》对应段落。不是四本书全文均投入每次请求；窗口不足会省略其他书的完整段落并记录数量，《子平真诠》不截断。不强制每项凑齐四书引用，也不能把后人评注冒充原作者正文。

每步大运必须给出运干、运支、格局喜忌变化、有利、不利、三个现实领域和待核条件。网页版原文引用现为可选：有适用原文再写；关系、评分与流年无引用也能生成，标为“模型推演”，不包装成古籍直接结论。引用做来源编号与连续文字校验，无法对应的摘录省略，缺少引用不再阻断报告。字面通过不代表语义适用性已经人工确认。

原局与各岁运层的每条程序关系都要对应解释：参与柱位 → 十神/格局/喜忌作用路径 → 可能现实表现 → 成立条件 → 其他解释/反证。允许条件性的工作、资源、合作等场景；不把合冲刑害直接等同于必然婚变、发财、事故、疾病或死亡。

## 分段生成与进度

八步原局先生成，之后前六步大运各生成一段，最后分别生成所选流年、可选流月、流日。六步正式大运时，第二档共 8 个请求阶段，第三档共 10 个请求阶段。页面在生成按钮前明确提示。

缩减范围不更改原始资料签名；同一输入的原局与前六步已完成阶段可复用，不再请求第七步及以后。完成数、汇总用量和导出内容仅统计本次范围。用户点击生成或继续后开始本轮运行，继续时附带已保存草稿与问题；内容校验失败可在本轮自动修正。

正文不设字数上限；模型仍有实际输出 Token 和上下文上限，程序按阶段发送，不能承诺一次无限输出。原局及每个岁运阶段若达到输出上限、格式错误或遗漏实质内容，携带最新草稿与校验问题自动修正一次；通过后继续，仍失败则保留最新草稿暂停。每次用户点击生成/继续，每阶段至多一次额外自动修正，没有递归或无限循环。网络、额度、限流及上下文预算错误直接暂停，不自动重试。引用缺失或无法核对时省略引用并保留模型推演，不据此触发修正。

8 / 10 是基础阶段数，自动修正属于额外模型请求，也可能计费；界面在调用前说明，并显示各阶段累计自动修正次数和结果。报告 Token 统计仅汇总通过校验阶段的响应，未计入失败请求，不作为完整账单；实际总用量以模型平台为准。

关系解释使用单独的本层必答清单，背景及运内逐年关系不混入顶层解释。错误会列出遗漏、多出或重复的关系 ID 与柱位。领域、评分维度及年度记录在键完整且无重复时由代码排序，避免仅因顺序不同而失败；缺失内容仍须模型补齐，不由代码编造。

报告请求读取等待上限调整为 600 秒，连接检查保持原有短等待设置。超时、接口错误和自动修正后仍失败时保存当前阶段、时间及安全错误说明，页面重新运行后仍可查看。模型因输出上限停止时保存已返回的正文（如有），不将截断内容当成完整报告；修正请求网络失败也保留此前草稿。错误记录及草稿仍只保留在当前网页会话，不写入磁盘。仅修改文件或打开页面不会发起模型请求。

已通过检查的阶段保留在当前页面/应用会话。点击继续只请求未完成阶段；内容或格式不完整时保存本段草稿，可手动修正对应阶段。仅放宽引用规则的升级会按原始输入签名精确匹配旧进度，匹配成功才复用；更换模型、命盘或所选时间范围会使原进度失效，防止旧报告混入新范围。退出应用或结束页面会话可能丢失进度；成功后及时下载。

HTML 报告包含代码生成的 SVG 与全部文字，打印时展开详情；TXT 包含全部解释、分项与逐年分数；JSON 包含完整结构及原文出处。安卓同样展示详细报告，并分块传递长结果。

## 本次检查范围

本轮只进行代码静态语法检查与构建，不运行测试、实际模型调用或真机试装。模型在各平台上遵循长结构输出的成功率及解释质量，仍需实际使用反馈与人工复核。
