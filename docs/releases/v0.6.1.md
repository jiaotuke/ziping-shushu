# v0.6.1 · 模型接入与公开站点加固

2026-10-25 发布公开源码和公开站点部署源码包。Skill源码与安装包保持原版；不重新构建Skill或EXE/APK。

## 主要变化

- 模型平台增加书生·端砚，报告与译文使用同一接入方式；检查密钥与模型时只读取模型列表。端砚采用平台默认推理设置，不混用其他平台的专有参数。
- 对端砚HTTP429保留官方英文错误码，区分 `rate_limit_exceeded` 和 `quota_exceeded`。平台可用性与账户额度以实际情况为准，限流时不会自动重试、切换模型或补充额度。
- 增加来源频率限制、连续失败验证码、全站2个AI任务及同一来源1个任务的并发限制，拒绝忙碌请求时保留当前报告及已完成阶段。
- 公开容器和网关增加资源与请求大小限制；提供服务器资源监测、部署前SQLite一致性备份及失败回滚工具。
