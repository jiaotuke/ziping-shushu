# 子平术数 v0.5.0

## 本次更新

- 可点击的子平 K 线；切换大运时同步展示白话概览、事业与学业/财务与资源/感情与合作三项解读。
- 大运说明、有利与留意事项、运内十年评分与完整解释，支持逐年或全部展开。
- 详细推导和古籍依据置于后方折叠；HTML 支持离线图表交互和完整打印。
- 保留前六步大运、自动修正与草稿恢复，修复编号格式误拦截；原文引用可选，缺分不补造。
- Windows/安卓更新同一套报告，不提供新增的无需排盘示例界面。正式解读需先排盘和古籍检索。

## 安装

Windows 10/11 64位：完整解压 ZipingShushu-Windows.zip，再打开 ZipingShushu.exe，保留 _internal 文件夹。
安卓 8.0+ ARM：安装 ZipingShushu-Android.apk，versionCode 5，沿用原签名。iPhone 无法安装 APK。

排盘、岁运和古籍在本地运行；AI 解读/译文使用用户自己的模型密钥。缓存和未下载的报告不随安装包交付。
