# 网页版公开源码更新 · 2026-10-28

- 新增普通用户登录、保存排盘、报告收藏与独立的“我的对话”。普通账号与代理登录独立。
- 排盘后进入结果页面，提供退出排盘与保存按钮；优化手机选择器及四柱、八柱同屏布局。
- 新增白话版与专业版报告，白话版保留子平K线，两种文风使用同一份评分数据。
- 报告后可进入独立“问问AI”页面，需VIP资格并使用访问者自己输入的模型API Key，不使用站点作者密钥。
- 问答从“查看完整推导与古籍依据”起完整保存正文，单独保留报告记载的四柱、性别、出生时刻；每轮发送完整正文和近期对话。容量不足时先减少历史轮次，仍放不下则明确提示，不截断报告。
- 每轮可依次多选大运、年、月、日；层级内部取并集，层级之间共同限定，不选即不限。流月按节气，选定范围附加关键词摘录，每轮记录北京时间及所选范围。
- 回答要求结合原局、所选时间干支关系和实际问题进行本轮分析，区分已有报告依据与新增推演；原文出处默认折叠展示。出处格式可在本地自动整理，不能核对的编号标为待核，不把结构校验等同于结论正确。
- 对话可手动保存或自选自动保存；每账号最多20段对话，每段最多50条消息，总空间10MB。VIP失效后仍可查看、下载、删除本人已保存对话。API Key不随收藏或对话保存。
- 登录有效期8小时；当前登录状态依赖网页会话。浏览器断开、刷新创建新会话或服务更新可能需要重新登录，未保存内容可能丢失。

验证：静态语法检查、本地页面及时间选择联动检查、线上HTTPS和容器健康检查。没有新增或运行自动化测试，也没有为验证实际调用模型；新回答文风仍需实际使用反馈。
