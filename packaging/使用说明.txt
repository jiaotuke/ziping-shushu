子平术数 · 便携版

Windows：完整解压 ZIP，双击 ZipingShushu.exe。
必须保留旁边的 _internal 文件夹，不要单独移动 EXE。
浏览器会自动打开，保留启动窗口；关闭启动窗口可退出服务。
适用 Windows 10/11 64 位电脑，无需安装 Python。

安卓：将 ZipingShushu-Android.apk 下载到手机，打开安装。
适用 Android 8.0 及以上 ARM 手机，可独立运行，无需电脑配合。
不是 iPhone 安装包。

本地可完成排盘、岁运与古籍检索。
Windows 默认按当地钟表时间排盘；联网加载地点后可选真太阳时。
安卓可在公历页选填出生经度与时区，进行真太阳时修正。
需要对古籍排序时，便携版采用段落关键词，不使用大型向量模型。

AI 解读、AI 译文需要联网及用户自己的模型 API Key。
不懂 API 接入可添加作者微信：bxzgf-bxbgf，备注「子平术数」。
咨询范围、费用和交付在微信沟通，软件内没有扫码支付或订单。
报告可下载为 HTML/TXT/JSON，HTML 可用电脑浏览器打印为 PDF。
安卓密钥和报告不自动保存，退出前请下载需要保留的报告。

当前为首个安装包版本，已完成构建与静态检查，尚未完成跨设备试装。

分享给别人时发送原始干净 ZIP 和 APK，不要附上自己的 user-data 文件夹。
